# Manuel d'utilisation — Panneau d'administration EYWEP-CDJS

---

## 1. Accès et connexion

### Se connecter
1. Accéder à l'URL : `https://votredomaine.com/login`
2. Saisir l'adresse e-mail et le mot de passe du compte administrateur
3. Cliquer sur **Se connecter**

> Si vous avez oublié votre mot de passe, cliquez sur **Mot de passe oublié** et suivez les instructions envoyées par e-mail.

### Se déconnecter
1. Cliquer sur l'**icône utilisateur** en haut à droite de la barre de navigation
2. Cliquer sur **Deconnexion** dans le menu déroulant

---

## 2. Tableau de bord

La page d'accueil de l'administration affiche :
- Les **statistiques globales** : nombre d'articles, activités, ressources, success stories
- Un **graphique** d'évolution des données

---

## 3. Gestion des articles

**Menu :** Sidebar → Articles

### Créer un article
1. Cliquer sur **Nouvel article**
2. Renseigner :
   - **Titre** (obligatoire)
   - **Date de publication**
   - **Description** — éditeur de texte riche (TinyMCE)
   - **Image de couverture** — JPG/PNG, recommandé 1200×630 px
   - **Images supplémentaires** — galerie photos de l'article
3. Cliquer sur **Enregistrer**

### Modifier / Supprimer un article
- Cliquer sur l'icône **crayon** pour modifier
- Cliquer sur l'icône **poubelle** pour supprimer (action irréversible)

---

## 4. Gestion des activités

**Menu :** Sidebar → Activités

Même fonctionnement que les articles. Chaque activité dispose de :
- Titre, date de publication, description (TinyMCE)
- Image de couverture + galerie d'images

---

## 5. Gestion des Success Stories

**Menu :** Sidebar → Success Stories

Même fonctionnement que les articles. Utilisé pour présenter les témoignages et réussites de bénéficiaires du programme.

---

## 6. Gestion des galeries photos

**Menu :** Sidebar → Galeries

### Créer une galerie
1. Cliquer sur **Nouvelle galerie**
2. Renseigner le **titre** et la **description**
3. Uploader les **photos** (sélection multiple possible)
4. Cliquer sur **Enregistrer**

---

## 7. Gestion des ressources

**Menu :** Sidebar → Ressources

Les ressources sont des documents téléchargeables (PDF, Word, etc.).

### Créer une ressource
1. Cliquer sur **Nouvelle ressource**
2. Renseigner :
   - **Titre** et **description**
   - **Catégorie**
   - **Fichier** à télécharger (PDF, DOC, DOCX, etc.)
   - **Image de couverture** (optionnel)
3. Cliquer sur **Enregistrer**

---

## 8. Gestion des projets

**Menu :** Sidebar → Projets

### Créer un projet
1. Cliquer sur **Nouveau projet**
2. Renseigner :
   - **Titre** et **description**
   - **Statut** : `Ouvert` / `Fermé` / `Archivé`
   - **Date de publication** et **date de clôture** des candidatures
   - **TDR** (Termes De Référence) — fichier PDF téléchargeable
   - **Image de couverture** + images supplémentaires
3. Cliquer sur **Enregistrer**

> **Important :** Quand la date de clôture est dépassée, le projet passe automatiquement au statut `Fermé` et le formulaire de candidature se désactive.

### Voir les candidatures d'un projet
Depuis la liste des projets, cliquer sur **Voir** puis accéder à l'onglet ou au lien **Candidatures**.

---

## 9. Gestion des candidatures

**Menu :** Sidebar → Candidatures

### Filtrer les candidatures
La liste peut être filtrée par :
- **Projet**
- **Statut** : En attente / Retenue / Rejetée
- **Recherche** par nom, prénom ou e-mail

### Consulter une candidature
Cliquer sur **Voir** pour accéder au détail complet :
- Informations personnelles (nom, prénom, pays, sexe, e-mail, téléphone)
- Documents soumis avec aperçu PDF intégré :
  - Lettre de motivation
  - Pièce d'identité
  - CV
  - Business plan simplifié *(si fourni)*
  - Plan financier prévisionnel *(si fourni)*
  - Documents légaux *(si fournis)*
  - Autres activités / preuves d'activité *(si fournies)*

### Changer le statut d'une candidature
1. Depuis le détail d'une candidature, localiser le bloc **Statut de la candidature**
2. Sélectionner : `En attente` / `Retenue` / `Rejetée`
3. Cliquer sur **Enregistrer**

### Exporter les statistiques
Depuis la liste des candidatures :
1. Cliquer sur **Exporter les statistiques**
2. Choisir le format : **PDF** ou **Excel**
3. Appliquer des filtres optionnels (projet, pays, sexe)
4. Télécharger le rapport

### Supprimer une candidature
Cliquer sur l'icône **poubelle** — tous les fichiers associés sont supprimés automatiquement.

---

## 10. Gestion des actualités (bandeaux)

**Menu :** Sidebar → Actualités

Les actualités sont des messages courts affichés en bandeau défilant sur le site public.

### Créer une actualité
1. Cliquer sur **Nouvelle actualité**
2. Renseigner le **titre** / **texte** et le **statut** (actif/inactif)
3. Cliquer sur **Enregistrer**

---

## 11. Gestion des partenaires

**Menu :** Sidebar → Partenaires

### Ajouter un partenaire
1. Cliquer sur **Nouveau partenaire**
2. Renseigner le **nom**, le **lien** vers son site web et son **logo**
3. Cliquer sur **Enregistrer**

---

## 12. Gestion des FAQs

**Menu :** Sidebar → FAQs

### Créer une question/réponse
1. Cliquer sur **Nouvelle FAQ**
2. Renseigner la **question**, la **réponse** et l'**ordre d'affichage**
3. Définir le **statut** : actif (visible) / inactif (masqué)
4. Cliquer sur **Enregistrer**

---

## 13. Paramètres du site

**Menu :** Sidebar → Paramètres → Front Office

Permet de personnaliser l'ensemble du site public :

| Section | Description |
|---------|-------------|
| **Identité** | Nom, slogan, logo, favicon |
| **Couleur principale** | Couleur du thème (boutons, liens, accents) |
| **Hero / Bannière** | Titre, sous-titre, images du slider, vidéo (YouTube/Vimeo) |
| **Coordonnées** | Adresse, téléphone, e-mail |
| **Réseaux sociaux** | Facebook, LinkedIn, Twitter/X, WhatsApp |
| **Google Maps** | Lien d'intégration de la carte (page Contact) |
| **Liens pied de page** | Liens utiles affichés dans le footer |

Cliquer sur **Enregistrer les paramètres** après chaque modification.

---

## 14. Gestion des comptes administrateurs

Il n'y a pas d'interface de création de compte dans le panneau. Les nouveaux comptes se créent via SSH :

```bash
cd ~/cdjs-eywep
php artisan tinker
User::create(['name'=>'Prénom Nom','email'=>'email@exemple.com','password'=>bcrypt('motdepasse')]);
```

---

## 15. Bonnes pratiques

- **Images** : toujours optimiser avant l'upload (< 1 Mo recommandé)
- **PDF** : taille maximale de 5 Mo pour les documents des candidats, 10 Mo pour les documents complémentaires
- **Sauvegarde** : exporter régulièrement les statistiques des candidatures
- **Sécurité** : ne jamais partager les identifiants de connexion
